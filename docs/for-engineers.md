# Trilha Engenheiro

Para CTO, Head of AI Platform e desenvolvedores. O BTV é um gateway: você troca o
`OPENAI_BASE_URL` do seu agente e toda chamada LLM passa a ser interceptada,
validada e auditada — sem modificar o código do agente.

## Comece por aqui

1. **[Quickstart](./quickstart.md)** — suba o stack e faça a primeira chamada governada.
2. **[Conceitos](./concepts.md)** — entenda o pipeline de decisão (a ponte para a trilha de Compliance).
3. **[API Reference](./api-reference.md)** — endpoints, payloads e códigos de resposta.
4. **[Integrações](./integrations/index.md)** — conecte LangChain, CrewAI, AutoGen, MCP ou os SDKs.
