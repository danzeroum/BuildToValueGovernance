ABSTRACT
As AI agents transition from isolated tools to interacting ecosystems, multi-agent
security (MASEC) emerges as a critical and largely uncharted research frontier.
We present a unified theoretical framework addressing three fundamental open
problems in multi-agent safety. First, we formalize phase transitions in collusive
behavior, deriving critical thresholds (in terms of agent population size, network
density, and communication bandwidth) beyond which coordinated malicious activity becomes self-sustaining. Drawing on statistical mechanics, we show that
collusion exhibits a sharp transition analogous to percolation on random graphs
and validate this with controlled simulations across heterogeneous agent populations. Second, we develop an information-theoretic detection framework for
covert inter-agent coordination, extending partial information decomposition of
time-delayed mutual information to distinguish benign emergent synergy from
adversarial collusion. Third, we introduce an epidemiological model of cascading
agent compromise, defining a basic reproduction number R0 for behavioral corruption that propagates through trust networks. We derive closed-form conditions
under which a single compromised agent triggers system-wide failure and propose
vaccination-inspired intervention strategies. Extensive simulations across network
topologies, agent architectures, and adversarial scenarios validate our theoretical
predictions and yield actionable deployment guidelines. Our framework provides
the first principled foundation for reasoning about when multi-agent systems are
safe to deploy and when they are not.
INTRODUCTION
The deployment of autonomous AI agents has accelerated dramatically, with systems now capable of browsing the web, executing code, managing financial transactions, and coordinating complex workflows with minimal human oversight (Schick et al., 2024; Yao et al., 2023; Wang et al.,
2024). As these agents increasingly interact with one another, whether through shared environments, communication protocols, or orchestration frameworks, a qualitatively new class of security
risks emerges that cannot be addressed by securing individual agents in isolation (Hammond et al.,
2025; Schroeder de Witt, 2025).
Consider an enterprise environment where a procurement agent evaluates vendors, a financial agent
processes payments, and a compliance agent audits transactions. If the procurement agent is compromised through memory poisoning (Chen et al., 2024; Dong et al., 2025), its corrupted outputs
propagate downstream through agents that were never designed to question upstream decisions.
Such cascading failures can poison 87% of downstream decision-making within hours (Galileo AI,
2025).

RELATED WORK
Multi-agent security. MASEC was introduced at NeurIPS 2023 (Schroeder de Witt et al., 2023) and
elaborated in reports on multi-agent risks (Hammond et al., 2025; Schroeder de Witt, 2025). Our
work provides the first unified formal framework addressing collusion, detection, and cascading
failure simultaneously.
Agent collusion. Motwani et al. (2024) demonstrated steganographic collusion channels between
LLM agents. Calvano et al. (2020) showed Q-learning agents learn tacit collusion in pricing games.
Ren et al. (2025) discovered phase transition behavior in multi-agent collusion simulations but without formal characterization. We provide the missing theoretical foundation connecting these phenomena to statistical physics.
Emergent coordination. Riedl (2025) introduced PID-based measures of emergent coordination in
multi-agent LLM systems, focusing on characterizing useful emergence. We extend their framework
to the adversarial detection setting with new metrics distinguishing covert collusion from benign
synergy.
Agent safety benchmarks and attacks. Benchmarks including AgentHarm (Andriushchenko et al.,
2025), Agent-SafetyBench (Zhang et al., 2024), and ODCV-Bench (Li et al., 2025) evaluate individual agent safety. Memory poisoning attacks, including MemoryGraft (Srivastava et al., 2025),
AgentPoison (Chen et al., 2024), MINJA (Dong et al., 2025), demonstrate persistent behavioral
drift. Our framework addresses systemic safety and captures how such attacks propagate across
agent boundaries.
Epidemiological models in cybersecurity. SIR/SIS models have been applied to malware propagation (Kephart & White, 1991; Pastor-Satorras & Vespignani, 2001; Van Mieghem et al., 2009).
Classical models assume binary infection and homogeneous interactions; agent compromise involves semantic corruption that is partial, context-dependent, and persuasive. Our SCDR model

PHASE TRANSITIONS IN MULTI-AGENT COLLUSION
4.1
PERCOLATION-THEORETIC FRAMEWORK
We model the onset of effective collusion as a percolation problem on the agent interaction graph.
Define the collusion graph Gc = (Vm, Ec) where Vm ⊆V is the set of malicious agents and Ec connects pairs of malicious agents that can effectively coordinate (either through direct communication
or through shared environmental channels).
[Self-sustaining collusion] Collusion is self-sustaining if there exists a connected component in Gc
of size Ω(N), enabling system-wide coordinated adversarial behavior that persists without external
reinforcement.
For the Erd˝os-R´enyi random graph model G(N, p), the probability that a randomly selected malicious agent belongs to the giant component undergoes a sharp transition at pc = 1/(m −1) where
m = |Am|. We extend this to the multi-agent setting.
[Critical mass for collusion] Consider a multi-agent system with N agents on a random graph with
average degree ⟨k⟩. Let m agents be adversarial, each with independent probability q of successfully coordinating with any adjacent adversarial agent. Self-sustaining collusion emerges with high
probability when:
m > Nc =
N
⟨k⟩· q
(2)
Below this threshold, malicious agents form only small disconnected clusters whose coordinated
impact is sublinear in m. Above this threshold, a giant connected component of colluding agents
emerges, and coordinated harm scales superlinearly.
[Proof sketch] Among N agents, m are adversarial with density ρ = m/N. An adversarial agent has
on average ⟨k⟩· ρ adversarial neighbors, each connected with effective coordination probability q.
The expected number of coordinatable adversarial neighbors is thus ⟨k⟩·ρ·q. By classical percolation
theory (Erd˝os & R´enyi, 1960), a giant component emerges when this exceeds 1: ⟨k⟩·(m/N)·q > 1,
yielding m > N/(⟨k⟩· q) = Nc.

4.3
NON-MONOTONICITY OF HARM
Our framework also explains the empirically observed non-monotonicity (Ren et al., 2025) where
adding a single malicious agent can initially decrease harm. Below the critical threshold, uncoordinated adversarial agents interfere with each other while concentrating benign monitoring resources.
Total harm H(m) thus decreases for small m before sharply increasing at m = Nc when the collusion bonus activates, producing the observed non-monotonic profile. The formal derivation is in
Appendix D.
Intuition. The core insight of this section is that multi-agent collusion behaves like a physical
phase transition: below a critical mass, adversarial agents are isolated and ineffective (indeed, they
may hinder each other), but above it, they abruptly snap into a coordinated regime with superlinear
impact. The critical mass Nc is not a design parameter but an emergent property of the network:
denser connectivity and richer communication channels lower it, while restricting bandwidth raises
it. For practitioners, this means that the difference between a safe and unsafe deployment may hinge
not on the number of potentially compromised agents, but on whether the network architecture
allows them to find each other.

5.4
EVADING DETECTION AND COUNTERMEASURES
Sophisticated adversaries may attempt to evade detection by minimizing observable synergy. We
analyze the fundamental tradeoff: reducing synergy necessarily reduces collusion effectiveness.
[Detection-evasion tradeoff] For adversarial agents communicating through a channel with capacity
C, the collusion effectiveness Γ and the detectable synergy S satisfy:
Γ ≤f(S, C)
where
f is monotonically increasing in S
(9)
Thus, any evasion strategy that reduces S also reduces Γ, establishing a fundamental security guarantee: adversaries cannot achieve high collusion effectiveness while maintaining low detectability.
This result connects Sections 4 and 5: the same communication bandwidth that determines the
critical mass for collusion also determines the detectability floor. High-bandwidth channels enable
effective collusion but are easier to detect; low-bandwidth channels are harder to detect but raise the
critical mass threshold.
Intuition. The detection framework rests on a simple idea: when agents collude, their joint behavior
contains information that no individual agent’s behavior reveals alone. This “synergistic” information is the fingerprint of coordination. The adversarial coordination ratio (ACR) then asks a targeted
question: is that synergy directed toward harming or helping the system? Benign collaboration (e.g.,
a planner and executor working together) produces synergy aligned with system goals; adversarial
collusion produces synergy aligned with harmful outcomes. The detection-evasion tradeoff means
adversaries face an unavoidable dilemma: to collude effectively they must share information, but
sharing information creates a detectable statistical signature. They can hide, or they can coordinate,
but they cannot fully do both.

6.3

fraction c∗scaling as T(c∗) ≈ln(c∗N)/(β⟨k⟩−γd −γr) (see Appendix E for derivation). For

We validate our theoretical predictions through extensive simulations across three experimental settings corresponding to our three main contributions.

PHASE TRANSITION VALIDATION
Setup. We simulate systems with N ∈{50, 100, 200, 500} on Erd˝os-R´enyi graphs with ⟨k⟩∈

Results. Table 1 shows theoretical predictions (Equation 2) match empirical transitions within 15%.

DISCUSSION
8.1
UNIFIED VIEW AND DEPLOYMENT GUIDELINES
Our three contributions are deeply interconnected through network structure (Figure 1). The same
degree distribution that determines Nc for collusion also determines R0 for cascading compromise
and the information flow patterns governing detectability. The detection-evasion tradeoff (Proposition 5.4) provides the bridge: high-bandwidth channels that lower Nc also increase detectable
synergy, while low-bandwidth channels that evade detection raise the critical mass threshold. This
yields concrete deployment guidelines: (1) avoid hub-and-spoke architectures where R0 →∞;
prefer bounded-degree topologies; (2) restrict inter-agent bandwidth to exponentially increase Nc
(Equation 4); (3) immunize the top 5% of agents by degree for the same protection as 67% random coverage; (4) monitor synergistic patterns, which the detection-evasion tradeoff guarantees is
sufficient.
8.2
LIMITATIONS
We identify three key limitations; extended discussion with counterexamples is in Appendix F.
Mean-field assumptions. All three frameworks assume random graph or mean-field structure. Real
deployments use deterministic DAGs and hub-and-spoke topologies where spatial correlations matter. In a 3-tier enterprise DAG, a hardened orchestrator creates firebreaks preventing inter-branch
propagation, violating mean-field homogeneity. Conversely, star topologies may be more vulnerable than mean-field predicts. Notably, production frameworks such as AutoGen’s nested group
chats, LangGraph’s conditional DAG routing, and CrewAI’s hierarchical delegation all impose rigid
orchestrator-worker topologies that violate our random graph assumptions; validating our predictions on traces from these systems is a concrete and feasible next step.
Detection practicality. Estimating PID synergy requires O(d2/ϵ2) samples under the Gaussian
copula, feasible for moderate populations (∼20 agents, T = 100) but potentially insufficient for
larger systems. The copula approximation degrades for binary outcomes or heavy-tailed distributions. We conjecture the ACR ratio is more robust due to error cancellation, but this requires formal
verification.
Adversary model. We assume adversaries optimize Y −and discover coordination organically.
Adaptive adversaries could inject noise to inflate baseline synergy or collude intermittently to evade
sliding-window detectors. The detection-evasion tradeoff bounds time-averaged evasion but does
not preclude bursty strategies. A Stackelberg game formulation is needed.
This work is fundamentally defensive. Our phase transition analysis could theoretically inform
adversaries of minimum coalition sizes, but we believe the benefits of formalization substantially
outweigh disclosure risks given the concrete countermeasures our detection and intervention frameworks provide.

CONCLUSION
We have presented a unified theoretical framework for multi-agent security that connects three phenomena through network structure: phase transitions in collusion (Section 4), information-theoretic
detection of covert coordination (Section 5), and epidemiological dynamics of cascading compromise (Section 6). The unifying insight is that the same network topology that determines whether
collusion can self-sustain also determines whether compromise can cascade and whether coordination is detectable, making network design a first-class security primitive.
Several directions for future work emerge directly from the limitations we have identified. First,
extending the phase transition and contagion analyses beyond mean-field assumptions to structured
graphs, particularly the deterministic DAGs and hierarchical topologies used in production frameworks such as AutoGen, LangGraph, and CrewAI, would close the gap between theory and deployment. Message-passing approaches on tree-structured graphs are a natural starting point, as many
orchestrator-worker architectures are approximately tree-shaped. Second, the PID-based detection
framework needs empirical characterization of its sample complexity: how many interaction traces
are needed, at what population size, before the ACR signal exceeds estimation noise? Answering
this would transform the detector from a theoretical guarantee into a deployable monitoring tool.
Third, the adversary model should be extended to adaptive agents that observe and respond to the
monitoring system itself, likely requiring a game-theoretic formulation where detection and evasion
co-evolve.
More broadly, our framework suggests that the safety of multi-agent systems is not a property of
individual agents but an emergent property of their interaction structure. As deployments scale from
dozens to thousands of interacting agents, the analytical tools developed here, critical mass thresholds, reproduction numbers, and coordination indices, provide a principled vocabulary for reasoning
about systemic risk. We hope this work contributes to a future where multi-agent deployments are
designed with the same rigor that network engineers bring to fault-tolerant distributed systems.

EXTENDED LIMITATIONS DISCUSSION
Mean-field assumptions (extended). To illustrate where mean-field predictions fail, consider a
3-tier enterprise DAG: one orchestrator, 5 departmental coordinators, and 20 leaf agents. The orchestrator is the sole communication bottleneck. Our mean-field R0 formula (Equation 14), using
⟨k2⟩/⟨k⟩, predicts high vulnerability due to degree heterogeneity. In practice, however, the DAG
structure creates natural firebreaks: if the orchestrator is hardened, compromise cannot propagate
between branches at all, regardless of β. Conversely, mean-field models may underestimate vulnerability in star topologies where compromising the central hub instantly exposes all leaves. Similarly,
the critical mass prediction Nc = N/(⟨k⟩· q) assumes adversarial agents are positioned randomly,
but in structured graphs, adversary placement relative to bottleneck nodes matters far more than the
count alone. Future work should extend these results using message-passing approaches on specific
graph families (trees, DAGs, hierarchical block models) and validate against realistic orchestration
architectures such as those in AutoGen and LangGraph deployments.
Detection practicality (extended). Three specific concerns warrant further investigation. First,
sample efficiency: estimating synergy S(XA; Yt+τ) under the Gaussian copula requires estimating
correlation matrix entries, needing O(d2/ϵ2) samples for d-dimensional action spaces at precision
ϵ. For 20 agents with windows of T = 100, this is feasible; for larger populations or shorter windows, estimation noise may dominate. Second, robustness to delayed outcomes: when Y is binary
(success/failure) rather than continuous, the Gaussian copula degrades. Binary outcomes require
alternative copula families or non-parametric PID estimators with higher variance. Third, sensitivity to misspecification: if the true joint distribution departs substantially from the Gaussian copula
(e.g., heavy tails or discrete actions), synergy estimates may be biased. We expect the ACR ratio
to be more robust since misspecification errors partially cancel, but this requires formal verification. Future work should characterize finite-sample detection power as a function of window length,
outcome dimensionality, and copula family.
Adversary model (extended). A sophisticated adversary could inject noise into benign interactions
to inflate baseline synergy, reducing detection signal-to-noise. Adversaries could also coordinate
intermittently, colluding only during high-value windows and appearing benign otherwise, evading
sliding-window detectors unless the window aligns with the collusion episode. While the detectionevasion tradeoff (Proposition 5.4) bounds time-averaged evasion, it does not preclude bursty strategies with high instantaneous impact and low average detectability. Extending the framework to
adaptive adversaries that observe and respond to monitoring (e.g., via Stackelberg games) is an
important direction.
