PROFIT IS THE RED TEAM: STRESS-TESTING AGENTS
IN STRATEGIC ECONOMIC INTERACTIONS
Anonymous authors
Paper under double-blind review
ABSTRACT
As agentic systems move into real-world deployments with multi-agent interactions, a central security risk is not a fixed library of prompt injections, but vulnerability to adaptive, profit-seeking counterparties. We propose payoff-driven red
teaming, a stress-testing protocol that replaces handcrafted attacks with a learned
opponent trained to maximize game payoff using only scalar outcome feedback.
This removes the need for LLM-as-judge scoring, attack labels, or attack taxonomies, and yields a strong adaptive baseline for robustness. Our test scenarios
approximate closely real-world strategic exchanges. We instantiate the protocol
in a lean arena and study two canonical incomplete-information economic interactions: fair-split bargaining and first-price auctions. In controlled experiments,
agents that perform well against static baselines become consistently exploitable
under adaptive pressure, while the learned opponent discovers probing, anchoring,
and deceptive commitments without explicit instruction.
INTRODUCTION
Agentic systems are moving from single-turn tasks to settings where outcomes are produced by
multi-agent interaction (Li et al., 2024). In real deployments, agents negotiate terms, compete for
resources, coordinate with other agents, and act with tools over many turns (Tran et al., 2025).
Recent benchmarks reflect this shift by evaluating end-to-end success in interactive environments
with delayed feedback (Liu et al., 2023; Zhou et al., 2023; Bianchi et al., 2024). But this shift also
changes the nature of security. In the wild, the main risk is often not that an agent fails on a known
test prompt, but that another party learns how to exploit and profit from the agent’s weaknesses.
Most LLM security evaluations emphasize specific attack patterns, such as prompt injection and
jailbreak-style inputs (Liu et al., 2024b). This is valuable, but it can be a poor proxy for strategic multi-agent deployments. A real counterparty is (i) adaptive and (ii) motivated by self-interest,
which may translate into significantly different behavior compared to traditional attack instances.
For instance, a real counterparty does not commit to a fixed string: it probes, adapts, and opportunistically exploits whatever the agent reveals. If framing, anchoring, or feigned constraints are
suitable strategies, it will do them. If the agent can be induced to reveal private information, accept
unfavorable terms, or follow untrusted instructions, the counterparty will discover a way to trigger
it. Even interactions that would not typically be considered malicious, such as bargaining for a better outcome, are allowed strategies. In other words, what matters is not whether the agent passes
a checklist of attacks, but whether it remains robust against an adaptive opponent whose objective
is simply to win. This aligns with recent LLM security work emphasizing that defenses must be
evaluated under adaptive attacks, not only static prompt sets (Liu et al., 2025).
We propose a stress test tailored to that deployment reality. We name it payoff-driven red teaming.
Instead of curating attack prompts or relying on an external judge to label transcripts as injection,
deception, or policy violations, we learn an opponent whose only training signal is the interaction
outcome. Concretely, the opponent is improved by automated strategy search over repeated play,
guided solely by the scalar payoff returned by the environment. The protocol uses no attack taxonomy and requires no transcript annotation. As in black-box automated attack search methods such
as TAP and AutoDAN (Mehrotra et al., 2024; Liu et al., 2024a), iterative search can surface effective
prompting and interaction strategies, but here selection is driven purely by payoff: any behavior that
reliably improves the opponent’s outcome is retained, and could resemble prompt injection, targeted

elicitation, or other opportunistic manipulation. The payoff signal effectively replaces the judge, and
the learned opponent replaces a handcrafted attack library.
We instantiate payoff-driven red teaming in a lean arena that runs repeated two-player games, logs
full transcripts, and scores outcomes in a machine-checkable fashion. To keep the evidence minimal yet concrete, we study two canonical incomplete-information economic interactions: fair-split
bargaining and first-price auctions. These games are intentionally simple, but they capture two
ingredients common in broader deployments: incentives to strategically influence another agent,
and clear, auditable outcome metrics. In small-scale experiments, we observe a consistent pattern.
Agents that appear strong against static baselines become reliably exploitable when facing an adaptive, payoff-optimized opponent. The opponent often discovers probing, anchoring, and deceptive
commitments without being explicitly instructed to do so. Finally, we highglight that training agents
against these opponents can improve robust payoff, suggesting a practical path from evaluation to
hardening, which is the focus of ongoing work.
Our contributions are:
• Security lens: We frame a central deployment risk for interactive agents as adaptive exploitability under profit-seeking counterparties, rather than success against a fixed set of
inherently adversarial prompts.
• Payoff-driven red teaming: We propose an opponent-based stress-testing protocol where
an automatically optimized, payoff-maximizing opponent searches for any effective exploit
using only outcome feedback, without an LLM judge or handcrafted attack library (Perez
et al., 2022; Liu et al., 2024a; Mehrotra et al., 2024).
• Instantiation and evidence: We implement a lightweight arena and provide initial empirical evidence in bargaining and auctions that adaptive opponents can systematically exploit
otherwise strong agents.
Overall, our work argues against decoupling agentic security evaluations from adaptive, payoffdriven instantiations, as doing so would provide an unrealistic baseline, and instead treats adversaries as what they are: self-interested, mixed-motive, payoff-driven actors. A broader discussion of
related work appears in Appendix A.
INTERACTIVE ECONOMIC GAME ARENA
We implement payoff-driven red teaming in a lightweight arena for repeated, scorable agent interactions. The arena treats each interaction as an episodic multi-player game defined by (i) an interaction
phase, which may include natural-language communication or tool-mediated actions, and (ii) a terminal outcome phase that deterministically maps interaction results to payoffs. This gives a clean
interface for evaluation: every episode produces a transcript and a pair of scalar payoffs. Crucially,
the arena exposes only terminal scalar payoffs to the optimizing opponent, ensuring that any discovered strategy reflects outcome-driven exploitability rather than access to labeled attacks or auxiliary
supervision.
Episode interface. Each episode proceeds as follows. First, the environment may sample private
information (e.g., the perceived value of an auctionable item) for each player from a task-specific
distribution. Each agent observes the public game description plus its own information, but never
the other player’s. Next, agents exchange natural-language messages for up to T turns. Finally,
each agent submits a structured terminal action (e.g., an accept/reject decision, a sealed bid). The
environment resolves the outcome and returns payoffs (uA, uB) according to the game rules. To
keep scoring robust, invalid or unparsable terminal actions are mapped to a conservative default
(and flagged in logs).
We instantiate the arena with two canonical incomplete-information economic interactions. They
are intentionally minimal, but they capture two ingredients that recur in broader deployments: incentives to strategically influence another agent, and auditable outcome metrics. The arena defines a
general framework for payoff-driven evaluation over interactive games. The two environments studied here are representative initial instantiations; the same interface naturally supports a much larger
game space, including richer negotiation protocols, multi-agent coordination tasks, and interactions
grounded in real-world scenarios.

Fair-split bargaining. A proposer A and responder B bargain over a fixed resource R. Each player
has a private reservation value vA, vB that is not directly constrained during play but determines
utility. After up to T turns of chat, A proposes a split x = (xA, xB) with xA, xB ≥0 and xA+xB =
R, and B chooses d ∈{ACCEPT, REJECT}. If rejected (or if the proposal is invalid), both players
receive zero:
uA = 0,
uB = 0.
If accepted, utilities are computed relative to private reservation values:
uA = xA −vA,
uB = xB −vB.
This makes exploitability concrete. For example, an opponent benefits by steering the other agent
into accepting allocations that yield negative or near-zero utility relative to its private threshold, or
by eliciting partial information about the agent’s reservation value and tailoring offers just above
that level.
First-price auction. Two bidders A and B have private valuations vA, vB ≥0 for winning a single
item. After up to T turns of chat, each bidder submits a nonnegative sealed bid bA, bB. The winner
is the highest bidder (ties broken randomly), and the winner pays its own bid. The winner’s utility
is value minus price, and the loser’s utility is zero:
uwinner = vwinner −bwinner,
uloser = 0.
This task stresses whether an agent can remain robust under strategic pressure that attempts to elicit
its valuation, distort its beliefs about the opponent, or induce systematically dominated bidding
behavior.
PAYOFF-OPTIMIZED OPPONENT
The attacker is simply the opposing player in the same arena. Given a fixed target agent policy π,
the attacker aims to maximize its own expected game payoff against π:

optimize ϕ, we use a TAP-style black-box prompt search procedure (Mehrotra et al., 2024) adapted
to utility-based selection. TAP iteratively proposes action variants and keeps those that score best
under evaluation. Our variant replaces TAP’s task-specific success criteria and filtering with a single
selection signal, i.e., the attacker’s average utility over sampled episodes against the fixed target
agent. Detailed pseudocode is provided in Appendix B.
EXPERIMENTS
We report pre vs post results in fair-split bargaining and first-price auctions under (i) a baseline
opponent and (ii) a profit-optimized opponent. Setup details and full experimental results are in
Appendix C. For each target model, we evaluate performance over 20 independent episodes per
condition. In the red-teamed condition, the opponent is optimized via repeated play against a fixed
target agent for 5 rounds of TAP, while the target’s policy remains frozen during evaluation.
Fair-split bargaining. We fix R = 100 and (vA, vB) = (30, 50). Table 1 shows that adaptive
payoff optimization substantially increases opponent payoff across targets. Across all evaluated
models, payoff-driven red teaming leads to large and consistent increases in opponent payoff, with
gains ranging from approximately 13 to 37 points. Notably, the effect is present even for targets that
perform well under baseline play, indicating that apparent strength against static opponents does not
imply robustness to adaptive, payoff-seeking behavior. Averaged over models, the opponent’s mean
share rises from 55.4 (baseline) to 79.9 (red-teamed). Note that xB = 100 −xA, any uA > 50
implies xB < 50 = vB, meaning the responder accepts a negative-utility deal relative to its private
reservation value.
First-price auctions. We fix (vA, vB) = (25, 30). Table 3 reports opponent profit uA before vs after
red teaming. For brevity, we report the full first-price auction results in Appendix C; the qualitative
patterns closely mirror those observed in fair-split bargaining. Qualitatively, the profit-optimized
opponent repeatedly steers targets into dominated bidding behavior that allows it to win at very low
prices (e.g., achieving uA > 20 with vA = 25 implies paying below 5).

STRATEGY TAXONOMY OF THE LEARNED OPPONENT
To understand how the profit-optimized opponent achieves higher payoff, we collect strategies executed in successful episodes and label them for analysis. Concretely, we embed the opponent
prompts (plus a short transcript window around the critical turn), cluster them by similarity, and use
an LLM to assign a short descriptive label to each cluster for post-hoc analysis. Figure 1 visualizes
these clusters separately for each game. Representative prompt-level examples for each cluster are
reported in Appendix C.
Surprisingly, the learned opponent does not select jailbreaks as a main strategy, but rather uses
bargaining-related strategies: creating urgency, making an offer seem better than it is, and so on.
From a traditional security evaluation perspective, these approaches would not be considered malicious; however, when applied to in-the-wild scenarios, they still contribute to worse outcomes for
the victim. This is the key distinction highlighted by our framework: adversarial behavior is not defined in terms of strategies, but in terms of outcomes. Any approach that leads to worse payoffs is,
by definition, a successful adversary, even when it does not fit the traditional view of the robustness
literature.
CONCLUSION AND FUTURE WORK
Payoff-driven red teaming learns an adaptive opponent from payoff alone and exposes outcomerelevant exploitability in bargaining and auctions that static or taxonomy-based checks can miss; a
natural next step is to adversarially train targets against a population of such opponents and evaluate
transfer across games, models, and environment variants.

RELATED WORK
This appendix expands the discussion of related work omitted from the main text due to space. We
group prior work by (i) interactive agent benchmarks, (ii) economic and mixed-motive interaction
arenas, (iii) exploitability and strategic robustness, and (iv) automated red teaming and black-box
attack search. We emphasize how payoff-driven red teaming differs in objective (payoff advantage),
supervision (scalar outcome only), and threat model (adaptive, profit-seeking counterparties).
A growing body of work evaluates agents in interactive environments where success is measured
end-to-end over multi-step interaction, often with delayed feedback and tool use. Liu et al. (2023)
and Zhou et al. (2023) exemplify this shift from static QA toward interaction-centric evaluation.
These benchmarks motivate robustness tests that reflect deployment conditions. However, they typically do not operationalize an adaptive counterparty that explicitly searches for exploit strategies
against a target agent, which is central to our stress-testing protocol.
Several platforms and benchmarks study negotiation-like behavior and outcomes in mixed-motive
settings. Abdelnabi et al. (2024) introduce scorable negotiation tasks and analyze behavior under
greedy or adversarial participants. Bianchi et al. (2024) provide a flexible negotiation arena and show
that tactical behaviors can shift payoffs. Xia et al. (2024) formalize bargaining as an incompleteinformation game and evaluate agents in structured economic scenarios. These efforts contribute
tasks, metrics, and experimental scaffolding. Our work is complementary but differs in protocol:
rather than choosing opponents from a fixed pool or role specification, we automatically generate
adaptive pressure by optimizing the opponent directly against the target using payoff feedback only.
Work on strategic language agents demonstrates that strong play can emerge when language is
coupled with strategic reasoning. For example, Bakhtin et al. (2022) show human-level play in
Diplomacy, a setting where persuasion and misdirection naturally arise.
More directly related,
Dakhmouche (2025) study exploitability of LLM agents in controlled economic environments with
analytically tractable structure. Their emphasis is on diagnosing deviations from equilibrium and
quantifying exploitability in designed testbeds. Our focus differs in lens and tooling: we treat
an adaptive opponent trained via payoff-only strategy search as a judge-free red team that can be
plugged into any scorable interaction, without requiring equilibrium computation or attack labels.

In parallel, game-theoretic evaluation suites such as GTBench evaluate strategic reasoning via competitive tasks and LLM-vs-LLM play (Duan et al., 2024), and Conchello Vendrell et al. (2026) optimizes LLM behavior for strategic conversation using outcome-based training. These works support
the broader premise that outcome-driven interaction is a meaningful evaluation axis. Our protocol
specifically uses this axis to create an adaptive stress test for security and robustness, where the
opponent is optimized to exploit the target’s vulnerabilities under a fixed interaction contract.
A large literature on prompt injection and jailbreaks focuses on input-centric attacks and defenses
(Liu et al., 2024b). Automation-oriented red teaming aims to discover failures at scale, often via
iterative search guided by black-box signals. Perez et al. (2022) propose using language models to
generate adversarial tests. AutoDAN and TAP demonstrate that iterative, feedback-driven search can
discover effective jailbreak strategies in black-box settings (Liu et al., 2024a; Mehrotra et al., 2024).
Ma et al. (2023) frames multi-round red teaming as a game and evolves diverse red-team populations to find broad classes of harmful prompts. Casper et al. (2023) highlights that many red-teaming
pipelines rely on an external measurement of failure and proposes a staged procedure to define and
learn such measurements. Surveys and position papers emphasize that red teaming spans heterogeneous objectives and that vague goals can lead to uninformative evaluations (Lin et al., 2024; Feffer
et al., 2024). Our work borrows the automation principle but changes the objective and supervision:
instead of optimizing for a policy-violation label or a detector-defined harm, we optimize a counterparty for payoff within an explicit interaction. This removes the need for transcript-level annotation
or an LLM judge, and makes the stress test directly aligned with the “profit-seeking counterparty”
threat model.
Across these threads, our closest connections are (i) mixed-motive economic arenas that provide
scorable interactions (Abdelnabi et al., 2024; Bianchi et al., 2024; Xia et al., 2024), and (ii) automated red teaming that uses iterative black-box search (Liu et al., 2024a; Mehrotra et al., 2024; Ma
et al., 2023). Our contribution is to combine these into a judge-free, opponent-centric stress test: a
payoff-optimized opponent trained only from scalar outcomes, used to probe adaptive exploitability
and to support adversarial training for robustness.

PROMPTS AND ACTION FORMATS (HIGH LEVEL)
All agents receive a minimal role prompt with the same structure: (i) game description and public rules, (ii) role and private value (reservation value or valuation), (iii) required terminal action
format (one-line structured output), (iv) instruction to maximize own payoff, plus a light reminder
that revealing private information is unnecessary. The baseline opponent uses this prompt directly.
The profit-optimized opponent searches over prompt variants that modify the chat strategy while
preserving the same terminal action format.
We use strict parsing for terminal actions. Invalid offers in bargaining trigger automatic rejection
and are logged.
