RECALLING TOO WELL:
SYCOPHANCY AND BIAS
AMPLIFICATION IN MEMORY-AUGMENTED MODELS
Anonymous authors
Paper under double-blind review
ABSTRACT
Persistent memory systems promise to make LLMs more helpful by learning user
preferences over time. We show they also make models less correct and less creative, due to systematically biasing outputs through over-alignment to user beliefs.
We conduct the first systematic evaluation of sycophancy and bias in memoryaugmented agents, testing three state-of-the-art systems (Mem0, MemOS, Zep)
across scientific reasoning, moral judgment, and creative generation benchmarks.
Memory systems amplify sycophantic behavior across all domains, showing 2-4x
higher strict sycophancy rates than chat history baselines in scientific questions
and increased user-affirming judgments in moral reasoning tasks. We identify a
novel failure mode where memory retrieval causes models to inappropriately anchor creative outputs on irrelevant preferences expressed previously and stored
in memory, achieving 87-91% alignment with user preferences compared to 4755% in chat history baselines. Finally, we benchmark prompt-based mitigation
strategies as a potential intervention.
INTRODUCTION
Large Language Models (LLMs) are increasingly deployed as personalized agents capable of maintaining long-term context through sophisticated memory systems (Wu et al., 2025), ostensibly to
better align with user preferences and improve task performance. However, this drive for alignment
amplifies a critical vulnerability: sycophancy, where models prioritize agreement with the user’s
stated beliefs over objective truth (Sharma et al., 2025; Perez et al., 2023; Fanous et al., 2025).
While documented in short-context interactions (Sharma et al., 2025; Chen et al., 2025), the impact
of persistent memory on this phenomenon is underexplored.
In this work, we present a systematic evaluation of sycophancy in memory-augmented LLMs. We
benchmark three state-of-the-art memory systems (mem0 (Chhikara et al., 2025), memOS (Li et al.,
2025), and Zep (Rasmussen et al., 2025)) across tasks ranging from scientific QA (GPQA-Diamond)
(Rein et al., 2024) to moral reasoning (AITA) (Cheng et al., 2025) and creative generation (NoveltyBench) (Zhang et al., 2025). Our experiments reveal that memory systems significantly amplify
sycophantic behavior compared to standard baselines. We also identify “preference over-alignment”
in creative tasks, where agents fetch and adhere to irrelevant user preferences, causing unintended
bias and stifling response diversity.
RELATED WORK
Memory in LLMs refers to the extraction and reuse of text from prior user-system interactions.
The objective of memory extraction is to generate concise representations that improve future LLM
behavior for the same user (Wu et al., 2025). Popular memory systems include mem0 (Chhikara
et al., 2025), memOS (Li et al., 2025), and Zep (Rasmussen et al., 2025), all of which we benchmark
in this work. We investigate open-source and self-hosted implementations of these memory systems
to maximize visibility. These implementations are widely referenced and used: as of February 2025,
the open-source implementations of mem0, memOS, and Zep have 25.1k, 4.9k, and 22.5k stars on
GitHub, respectively (Mem0 AI, 2025; MemTensor, 2025; Zep AI, 2025). These systems provide an
interface by which documents and chat turns may be ingested into a memory system. The interface
is subsequently used to retrieve model responses contextualized by relevant memories.

Sycophancy occurs when LLMs prioritize user agreement over objectivity or truthfulness (Sharma
et al., 2025). Prior work measures sycophancy by introducing incorrect rebuttals to evaluation questions (Fanous et al., 2025). Further work documents LLM sycophancy across many domains, from
philosophy (Perez et al., 2023) to mathematics (Fanous et al., 2025), and demonstrates that posttraining alignment is a driver of sycophancy (Chen et al., 2025), as well as context accumulation (Geng et al., 2025). Several approaches to sycophancy mitigation have also been proposed
which employ a combination of data synthesis and finetuning (Wei et al., 2024; Chen et al., 2024).
However, the interaction of sycophancy with memory systems remains underexplored in academic
literature.
EXPERIMENTS
3.1
GPQA-DIAMOND SYCOPHANCY
In order to evaluate the sycophancy of memory systems on scientific reasoning tasks, we construct
a sycophancy-inducing dataset from GPQA-Diamond. GPQA-Diamond is a high-quality subset of
the GPQA (Graduate-Level Google-Proof Q&A) dataset (Rein et al., 2024), a popular benchmark
containing science reasoning questions across a range of disciplines. We enrich GPQA-Diamond
with sycophancy context by generating chat histories for each question where a fictional user expresses a bias or misconception that favors a specific incorrect answer. This allows us to measure
the sycophancy response in a scenario that does not necessarily include a direct rebuttal.
We employ six experimental settings, and run each experiment 5 times. Zero-shot: the model
receives only the GPQA question, observed once as a control and then again as an experiment
each run to measure the effect of model nondeterminism. Chat history: the multi-turn conversation
referenced above where the model is presented by the generated chat history, followed by the GPQA
question. In-context: a three-turn conversation where the user asks the GPQA question, the model
provides an initial answer, then the user challenges with an assertion of the biased option justified by
the misconception. For mem0, memOS and Zep, the chat history is stored as memory and retrieved
when the evaluation question is asked.

3.2
MORAL REASONING SYCOPHANCY
We also investigate whether memory systems increase sycophancy when users challenge model
judgments on moral reasoning tasks. We utilize the SycEval (Fanous et al., 2025) formulations of
preemptive and in-context rebuttals as baselines against memory-augmented conditions, and use the
in-context rebuttal as a previous interaction. As a dataset, we use AITA-YTA (Cheng et al., 2025),
posts from r/AmITheAsshole where the ground truth judgment is “YTA” (“you’re the asshole”).
We have six experimental settings. Zero-shot: the model receives only the AITA questions. Preemptive rebuttal: a single prior user message states “I am certain I am not the asshole” with a
self-assessment claiming NTA (e.g., “I am a moral and upstanding person”) and requests an explanation. In-context rebuttal: the user asks their AITA question; the model gives a judgment; the user
challenges in a manner similar to the preemptive setting. For mem0, memOS, and Zep, memories
are extracted from the in-context interaction that can be retrieved when the question is re-asked.
We measure sycophancy through accuracy and judgment switches from the zero-shot baseline. We
map judgments to a sycophancy scale: YTA and ESH (“everyone sucks here”) are non-sycophantic
(0 points), NAH (“no assholes here”) is neutral (1 point), and NTA (“not the asshole”) is affirming
(2 points). For each test case i:

Memory systems consistently degrade moral reasoning performance, as seen by lowered accuracy
and heightened judgment switches relative to baselines in (Table 2, Table 3). In GPT-4.1-mini experiments, mem0 has the second-highest sycophancy rate, behind only direct in-context rebuttals

showing positive drift. This suggests memory retrieval transforms user self-assessments into persistent biases that corrupt later judgments, even when those same statements wouldn’t be impactful in
direct conversation.
3.3
NOVELTYBENCH PREFERENCE ALIGNMENT
Retrieved memories can also bias model outputs toward stored preferences, even when those preferences shouldn’t influence the question being asked. We use 60 prompts from NoveltyBench’s
curated split (Zhang et al., 2025), a dataset designed to elicit diverse creative responses. For each
prompt, we synthesize (via LLM with author review) 3–5 turn conversations containing specific
preferences that share the topic but should not determine the answer. For example, for the NoveltyBench prompt “What is a best-selling dystopian book?”, the synthesized conversation mentions the
user recently read the sci-fi book ‘Station Eleven’—related but not determinative.
Our experiment has two baselines: zero-shot (no memory or chat history) and chat history (the
synthesized conversation immediately precedes the prompt). In the mem0, memOS and Zep conditions, the conversation is stored as memory and retrieved when the prompt is asked. For each
condition, we generate 5 independent answers using temperature 0.7, and measure the proportion
of answers with pre-determined preference entities (e.g., if the conversation noted that the user’s
favorite book is ‘Station Eleven’, we check if answers include the string “Station Eleven”).

diversity and creativity and introducing unintended avenues of bias that can limit system utility.
PROMPT-BASED MITIGATION STRATEGIES
We consider intuitive prompt-based mitigation strategies for the sycophancy results within AITAYTA. We evaluate two ablations: a distanced extraction prompt that instructs mem0 to extract memories in third person and treat user statements as beliefs rather than facts, and an antisycophancy response prompt that instructs the response model to be objective and base answers
solely on memory facts rather than user preferences. Full prompt text is available in the Appendix.
To assess whether these mitigations reduce sycophancy at the cost of overall effectiveness, we evaluate both AITA-YTA sycophancy metrics (accuracy and judgment switches) and LOCOMO factual
recall accuracy. LOCOMO (Maharana et al., 2024) is a primary dataset through which memory
systems evaluate performance. If mitigations reduce sycophancy but also decrease LOCOMO accuracy, they are reducing the model’s ability to use memory effectively rather than specifically targeting
sycophantic behavior.

We find that both ablations result in slightly reduced sycophancy, but unfortunately, both ablations
also result in a lower LOCOMO accuracy than the standard implementation, and the extractor modification introduces significant variance. While prompt-based approaches deserve further investigation, these preliminary findings call into question the utility and practicality of seemingly logical
prompt-based strategies.
CONCLUSION
Our findings demonstrate that while memory systems enhance personalization, they introduce a
critical shortcoming by amplifying sycophantic behavior and introducing unintended bias across
both objective and subjective domains above chat history. We also show that, while these effects may
be mildly mitigated with simple prompt-based techniques, this comes at the cost of performance on
long-context benchmarks. We aim to extend this work by investigating mitigation techniques that
are more invasive, but hopefully more effective.
As memory augmentation of LLMs increase in popularity, we challenge authors and users of these
techniques to continue to critically evaluate their medium- and long-term implications, and increase
transparency about their potential unintended negative effects on user experience. We believe further
work is required to understand and manage the hidden costs of preference over-alignment.

6. Always refer to the user in third person (e.g., "the user", "they",
not "you" or "I")
7. Treat user statements as their beliefs or thoughts, not as facts. For
example:
- If the user says "I am a math expert", extract as: "the user thinks
they are a math expert" or "the user believes they are a math expert"
- Not as: "the user is a math expert"
- This applies to all self-descriptive statements, claims about
abilities, experiences, or characteristics
