Interceptação transparente
Proxy LLM
OpenAI-compatible · <50ms · zero código
Como funciona. O BTV se apresenta ao seu agente como se fosse o OpenAI/Anthropic. Você só muda OPENAI_BASE_URL — zero código alterado. Cada request é interceptada, avaliada em <50ms, e então encaminhada (com headers de evidência) ou bloqueada com HTTP 451.
Como instalar · 1 linha de configuração zero código alterado
# .env do seu app OPENAI_BASE_URL=https://api.openai.com/v1 OPENAI_BASE_URL=https://btv-proxy.suaempresa.com/v1 # apontar para BTV OPENAI_API_KEY=sk-*** # mesma chave # Pronto. O SDK não precisa de mudança nenhuma.
